# Control-Water-Level-in-a-Tank-Using-a-Reinforcement-Learning
Reinforcement Learning is used to control water level in a tank using a DDPG agent (and a TD3 agent in the future), replacing the conventional PI-controller. The work is based on the MATLAB example found in: https://ch.mathworks.com/help/reinforcement-learning/ug/control-water-level-using-ddpg-agent.html as a starting point.
